# Armada LSFG v0.1.2

## 🇫🇷 Français

### Nouveautés et corrections

- Ajout de la prise en charge de plusieurs bibliothèques Steam.
- Les jeux installés sur une carte microSD ou dans une bibliothèque Steam secondaire sont maintenant détectés.
- Lecture des bibliothèques Steam déclarées dans `libraryfolders.vdf`.
- Les bibliothèques amovibles non montées sont ignorées proprement.
- Gestion des manifests Steam pouvant rester temporairement en double après le déplacement d'un jeu entre deux bibliothèques.
- La bibliothèque Steam principale continue de fonctionner comme auparavant.

### Documentation

- Ajout d'un guide de mise à jour pour les utilisateurs ayant déjà une ancienne version d'Armada LSFG.
- Ajout d'une procédure de désinstallation.
- Documentation de la conservation des configurations et des sauvegardes lors d'une mise à jour.

### Important

- Armada LSFG ne modifie pas les Steam Launch Options.
- Cette release n'ajoute pas la prise en charge des jeux Linux natifs par LSFG-VK.

---

## 🇬🇧 English

### Changes and fixes

- Added support for multiple Steam libraries.
- Games installed on a microSD card or in a secondary Steam library can now be detected.
- Steam libraries are discovered from `libraryfolders.vdf`.
- Unmounted removable libraries are safely ignored.
- Handles duplicate Steam manifests that may temporarily remain after moving a game between libraries.
- The primary Steam library continues to work as before.

### Documentation

- Added update instructions for users who already have an older Armada LSFG version installed.
- Added an uninstall procedure.
- Documented configuration preservation and backups during updates.

### Important

- Armada LSFG does not modify Steam Launch Options.
- This release does not add LSFG-VK support for native Linux games.
