# Armada LSFG v0.1.3

## 🇫🇷 Français

### Actualisation

- L'actualisation automatique complète ne se lance plus à chaque ouverture par défaut.
- Lors de la première ouverture, Armada LSFG effectue une détection complète.
- Une fois la couche Vulkan, `Lossless.dll`, `conf.toml` et l'architecture détectés correctement, les ouvertures suivantes utilisent le cache et l'actualisation devient manuelle.
- Le bouton **Actualiser** reste disponible à tout moment.
- Ajout d'un réglage **Actualisation automatique** sous le bouton Actualiser pour choisir entre :
  - actualisation automatique à chaque ouverture ;
  - actualisation manuelle après la première détection réussie.
- Le choix est sauvegardé dans les paramètres Armada LSFG.

### Progression

- Ajout d'une barre de progression pendant l'actualisation.
- Affichage du pourcentage.
- Affichage de l'étape en cours et du jeu Steam actuellement analysé.

### Performances

- Ajout d'un cache pour l'état LSFG et la liste des jeux Steam.
- Les ouvertures en mode manuel utilisent directement les données mises en cache.
- Le scan des exécutables Steam utilise maintenant un seul parcours par jeu au lieu de deux.
- Le scan évite des vérifications inutiles sur les fichiers qui ne sont pas des `.exe`.
- Les bibliothèques Steam multiples et les jeux sur microSD restent pris en charge.

### Important

- Armada LSFG ne modifie pas les Steam Launch Options.
- L'actualisation manuelle force toujours une nouvelle détection complète.

## 🇬🇧 English

### Refresh behavior

- A full automatic refresh no longer runs every time Armada LSFG is opened by default.
- On the first opening, Armada LSFG performs a complete detection.
- Once the Vulkan layer, `Lossless.dll`, `conf.toml` and architecture have been detected successfully, later openings use cached data and refresh becomes manual.
- The **Refresh** button remains available at all times.
- Added an **Automatic refresh** setting below the Refresh button to choose between:
  - refreshing automatically every time the plugin is opened;
  - manual refresh after the first successful detection.
- The selected mode is saved in Armada LSFG settings.

### Progress

- Added a progress bar during refresh.
- Added percentage display.
- Added the current refresh stage and the Steam game currently being scanned.

### Performance

- Added caching for LSFG status and the Steam game list.
- Openings in manual mode load cached data directly.
- Steam executable scanning now uses one filesystem traversal per game instead of two.
- The scan avoids unnecessary checks on files that are not `.exe` files.
- Multiple Steam libraries and microSD-installed games remain supported.

### Important

- Armada LSFG does not modify Steam Launch Options.
- Manual refresh always forces a new full detection.
