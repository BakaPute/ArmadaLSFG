# Armada LSFG v0.1.4

## 🇫🇷 Français

### Interface bilingue automatique

- Ajout d'une interface française et anglaise.
- Les appareils dont la langue principale commence par `fr` affichent Armada LSFG en français.
- Tous les autres appareils affichent Armada LSFG en anglais par défaut.
- La langue est détectée automatiquement à partir de la langue du système / navigateur utilisé par Decky.
- Les sections, boutons, descriptions, notifications, erreurs principales et messages de progression sont traduits.
- Les messages de progression du backend sont traduits côté interface sans modifier le fonctionnement du backend.

### Compatibilité

- Aucun changement au format des profils existants.
- Les paramètres et profils créés avec les versions précédentes restent compatibles.
- Le cache d'actualisation de la v0.1.3 reste compatible.
- Les bibliothèques Steam multiples et les jeux installés sur microSD restent pris en charge.

### Important

- Armada LSFG ne modifie pas les Steam Launch Options.
- Cette version ne modifie pas le fonctionnement LSFG-VK ; elle ajoute principalement la localisation automatique de l'interface.

## 🇬🇧 English

### Automatic bilingual interface

- Added French and English user interfaces.
- Devices whose primary language starts with `fr` display Armada LSFG in French.
- All other devices display Armada LSFG in English by default.
- The language is detected automatically from the system / browser locale used by Decky.
- Sections, buttons, descriptions, notifications, main errors and refresh progress messages are translated.
- Backend refresh messages are translated in the interface without changing backend behavior.

### Compatibility

- No change to the existing profile format.
- Settings and profiles created with previous versions remain compatible.
- The v0.1.3 refresh cache remains compatible.
- Multiple Steam libraries and games installed on microSD remain supported.

### Important

- Armada LSFG does not modify Steam Launch Options.
- This release does not change LSFG-VK behavior; it mainly adds automatic interface localization.
