# Armada LSFG v0.1.5

## 🇫🇷 Français

### Nouvelle gestion des profils

- Les profils LSFG ne sont plus tous affichés les uns à la suite des autres.
- Ajout d'une liste repliable pour choisir un jeu possédant déjà un profil.
- Ajout d'une liste séparée pour les jeux pouvant être ajoutés à LSFG.
- Les paramètres du jeu sélectionné apparaissent directement sous la liste.
- La sélection manuelle reste affichée après la modification d'un réglage.

### Détection automatique du jeu en cours

- Armada LSFG détecte automatiquement les profils LSFG utilisés par les jeux en cours d'exécution.
- Le jeu en cours apparaît automatiquement dans l'interface sans devoir être sélectionné manuellement.
- Lorsqu'un autre jeu est sélectionné, les deux profils peuvent être affichés simultanément.
- Le jeu sélectionné manuellement est affiché au-dessus du jeu en cours afin de faciliter la comparaison des réglages.
- Un même profil n'est jamais affiché deux fois.

### Interface

- L'interface reste automatiquement en français sur les appareils francophones.
- L'anglais reste utilisé par défaut sur les autres appareils.
- Les réglages existants restent modifiables :
  - activation LSFG ;
  - exécutable ;
  - multiplicateur ;
  - Flow Scale ;
  - Performance Mode ;
  - suppression du profil.

### Compatibilité

- Aucun changement au format des profils existants.
- Les profils, paramètres et caches créés avec les versions précédentes restent compatibles.
- Les bibliothèques Steam multiples et les jeux installés sur microSD restent pris en charge.

### Important

- Armada LSFG ne modifie pas les Steam Launch Options.
- Cette version ne modifie pas le fonctionnement de LSFG-VK.

## 🇬🇧 English

### New profile management

- LSFG profiles are no longer displayed one after another in a long list.
- Added a collapsible list for choosing a game that already has a profile.
- Added a separate list for games that can be added to LSFG.
- The selected game's settings appear directly below the list.
- The manual selection remains visible after changing a setting.

### Automatic running-game detection

- Armada LSFG automatically detects LSFG profiles used by currently running games.
- The running game appears automatically without requiring manual selection.
- When another game is selected, both profiles can be displayed at the same time.
- The manually selected game is displayed above the running game to make setting comparisons easier.
- The same profile is never displayed twice.

### Interface

- The interface remains automatically French on French-language devices.
- English remains the default on all other devices.
- Existing settings remain editable:
  - LSFG enable state;
  - executable;
  - multiplier;
  - Flow Scale;
  - Performance Mode;
  - profile removal.

### Compatibility

- No change to the existing profile format.
- Profiles, settings and caches created by previous versions remain compatible.
- Multiple Steam libraries and games installed on microSD remain supported.

### Important

- Armada LSFG does not modify Steam Launch Options.
- This release does not change LSFG-VK behavior.
